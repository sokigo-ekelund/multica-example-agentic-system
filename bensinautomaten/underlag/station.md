# Station 7 – fakta om automaten

- **Namn på kvittot:** Bensinautomaten · Station 7, Exempelvägen 1, 123 45 Exempelstad
- **Öppet:** dygnet runt, obemannat. Stationsföreståndaren nås via ärendet (eskalering).
- **Betalning:** endast kort med PIN. Ingen kontant betalning.
- **Reservation:** automaten reserverar ett belopp innan pumpen startar. Standard är det högsta tillåtna
  beloppet enligt `prislista.json`. Det som inte används hävs när tankningen avslutas.
- **Spolarvätska:** säljs vid pumpen, 4-litersdunk. Läggs på samma kvitto.
- **Priser:** se `prislista.json`. Priset gäller vid tankningstillfället.
