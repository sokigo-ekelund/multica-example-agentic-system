# Leveranser

Här sparar agenten **Skribent** färdiga artiklar som `<ÄRENDE>-<kort-namn>.md`.
Orkestratorn sparar samlingsfiler som `<ÄRENDE>-startpaket.md`.

Mappen är tom från början. Ett exempel på en godkänd artikel finns i
[`demo-uppdrag/facit/exempel-artikel.md`](../demo-uppdrag/facit/exempel-artikel.md).
